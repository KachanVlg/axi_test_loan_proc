Необходимо разработать приложение, реализующие оформление кредита с использованием следующего стека технологий: Spring MVC, Hibernate, PostgreSQL.

Общий процесс выглядит следующим образом:
1) оформление заявки на заём
2) принятие решения по кредиту
3) подписание договора займа

1) Пользователь создает заявку на кредит. Информация о клиенте:
ФИО
Паспорт
Пол
Семейное положение
Адрес проживания
Адрес регистрации
Телефон
Сведения о занятости(период работы, должность, название организации)
Сумма желаемого кредита (добавьте в необходимую сущность)
Любое кастомное поле с названием в контексте задания

2) После оформления заявки на кредит система случайным образом принимает решение о заёме. Необходимо зафиксировать само решение, предлагаемый срока в днях (1-12 месяцев), одобренную сумма кредита.

3) После одобрения кредита, система должна позволить подписать заём. Кредитный договор должен содержать информацию из заявки, дату подписания, а также статус подписи. Также необходимо добавить в корень проекта файл с названием AXITEST.MD, внутри указать используемую версию библиотеки hibernate-core.

Система должна предоставлять следующий дополнительный функционал:
1) Вывод списка всех клиентов
2) Поиск клиента по телефону, ФИО и паспортным данным
3) Выводить список заявок со статусом одобрения
4) Выводить список всех подписанных кредитных договоров со статусом подписания

Для выполнения задания необходимо приложить SQL скрипт для создания БД.

Основное требование к интерфейсу приложения – выполнение описанных функций, красивое оформление, стили можно не делать.

2. Реализация сервисов и репозиториев при необходимости
3. Тесты в постмане
